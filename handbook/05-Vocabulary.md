# 词汇 | Vocabulary

本章节收录学习过程中遇到的重要词汇。词汇按词性分组；动词的活用规则统一参见 Verbs 章节。

## 名词

|------|------|------|------|----------------|------|

| <a id="W-N002"></a>W-N002 | 用意 | ようい | 准备；把马上要使用的具体东西备好 | デートの用意をする；比「準備」更强调具体物品 | デートの用意（ようい）をしました。<br>为约会做好了准备。 |
| <a id="W-N003"></a>W-N003 | 準備 | じゅんび | 准备；为将来的行动或计划做系统安排 | 旅行の準備をする；范围通常比「用意」广 | 旅行（りょこう）の準備（じゅんび）を始（はじ）めました。<br>开始为旅行做准备。 |
| <a id="W-N004"></a>W-N004 | 夕方 | ゆうがた | 傍晚；下午接近晚上的时段 | 夕方に | 夕方（ゆうがた）に買（か）い物（もの）へ行（い）きます。<br>傍晚去买东西。 |

| <a id="W-N007"></a>W-N007 | 同僚 | どうりょう | 同事；同僚 | 上司や同僚 | 上司（じょうし）や同僚（どうりょう）に説明（せつめい）するためです。<br>这是为了向上司和同事说明。 |
| <a id="W-N008"></a>W-N008 | 売上 | うりあげ | 销售额；营业额 | 今月の売上；売上を上げる | 今月（こんげつ）の売上（うりあげ）をレポートに書（か）きます。<br>把本月销售额写进报告。 |
| <a id="W-N009"></a>W-N009 | レポート | — | 报告；报告书 | レポートを書く | レポートは仕事（しごと）の結果（けっか）を書（か）くものです。<br>报告是用来记录工作结果的。 |
| <a id="W-N010"></a>W-N010 | ホチキス | — | 订书机 | ホチキスで留める | ホチキスで書類（しょるい）を留（と）めます。<br>用订书机把文件订起来。 |
| <a id="W-N011"></a>W-N011 | 大人 | おとな | 成人；大人 | 通常单独说「大人」；「大人の人」并非绝对错误，但常显得重复 | 大人（おとな）でも分（わ）からないことがあります。<br>即使是大人，也有不懂的事情。 |
| <a id="W-N012"></a>W-N012 | 半日 | はんにち | 半天 | 半日かかる | 修理（しゅうり）に半日（はんにち）かかりました。<br>修理花了半天。 |
| <a id="W-N013"></a>W-N013 | 男 | おとこ | 男人；男性 | 比「男の人」更简短但语气更直接；礼貌中常说「男性」 | あの男（おとこ）は日本人（にほんじん）です。<br>那个男人是日本人。 |
| <a id="W-N014"></a>W-N014 | 男性 | だんせい | 男性 | 正式、中性；「日本の男性」比「日本の男の人」简洁 | 日本（にほん）の男性（だんせい）について調（しら）べています。<br>我正在研究日本男性。 |
| <a id="W-N015"></a>W-N015 | 気持ち | きもち | 心情；感觉 | 気持ちがいい／悪い | 今（いま）は落（お）ち着（つ）いた気持（きも）ちです。<br>我现在心情很平静。 |
| <a id="W-N016"></a>W-N016 | 理由 | りゆう | 理由；原因 | 理由がある／理由を説明する | 特別（とくべつ）な理由（りゆう）があったかもしれません。<br>也许有特别的理由。 |
| <a id="W-N017"></a>W-N017 | 思い出 | おもいで | 回忆；往事 | 子供の時の思い出 | 箱（はこ）に「70年代（ねんだい）の思（おも）い出（で）」と書（か）いてあります。<br>箱子上写着“70年代的回忆”。 |
| <a id="W-N018"></a>W-N018 | 方法 | ほうほう | 方法；办法 | 方法を考える／この方法 | この方法（ほうほう）が一番（いちばん）分（わ）かりやすいと思（おも）います。<br>我觉得这个方法最容易理解。 |
| <a id="W-N019"></a>W-N019 | 結果 | けっか | 结果；成果 | 結果を書く／結果を説明する | レポートには仕事（しごと）の結果（けっか）を書（か）きます。<br>报告中要写工作成果。 |
| <a id="W-N020"></a>W-N020 | 情報 | じょうほう | 信息 | 情報を集める／情報が多い | 会社（かいしゃ）にはたくさんの情報（じょうほう）があります。<br>公司里有很多信息。 |
| <a id="W-N021"></a>W-N021 | 雪 | ゆき | 雪 | 雪が降る／雪が付く | 顔（かお）に雪（ゆき）がたくさん付（つ）いています。<br>脸上沾着很多雪。 |
| <a id="W-N022"></a>W-N022 | 顔 | かお | 脸；面孔 | 顔に付く／顔を見る | 顔（かお）に雪（ゆき）が付（つ）いています。<br>脸上沾着雪。 |
| <a id="W-N023"></a>W-N023 | 庭 | にわ | 庭院 | 庭にいる／庭で遊ぶ | 東京（とうきょう）の庭（にわ）に熊（くま）が来（く）ることはありません。<br>东京的院子里不会有熊来。 |
| <a id="W-N024"></a>W-N024 | 荷物 | にもつ | 行李；包裹 | 荷物を持つ／荷物を送る | 旅行（りょこう）の荷物（にもつ）を用意（ようい）しました。<br>准备好了旅行行李。 |
| <a id="W-N025"></a>W-N025 | 入り口 | いりぐち | 入口 | 入り口を閉める | 入（い）り口（ぐち）を閉（し）めたら大丈夫（だいじょうぶ）です。<br>把入口关上就没问题了。 |
