把错题记录到 GitHub

两个板块下方各有一个「再出题」按钮，可以各自加练一组；加完题后再提交一次，新题的对错会一并上报。 空着的题不算错、也不上报，所以做了一半就可以先提交，剩下的填好之后再提交一次。 提交后仓库会记录错题，明天的练习会优先复习做错的知识点；连续答对后该知识点自动退出复习队列。 Issue 建好之后回到应用，记录会自动清除（应用会核对仓库里已入库的日期）。没提交成功的结果一直留在本机，下次打开会出现在顶部提示条里。「已提交，清除本机记录」按钮是离线时的手动退路。也可以用「复制结果 JSON」自己新建 issue 粘贴（记得加 exercise-result 标签）。
